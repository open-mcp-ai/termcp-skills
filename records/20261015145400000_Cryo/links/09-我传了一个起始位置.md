# 09 · 我传了一个起始位置

## 我手里有什么

两天的探针都通了，我要开始测"等待"这个功能本身。

## 我做了什么

我在终端里挂了一个耗时的命令，然后用读输出工具等它。

```json
{"shell_id": "...", "offset": 8311, "timeout": 60}
```

## 出来什么

**它立刻返回了，而且返回的是空的。**

```
{"bytes_returned":0, "end_offset":8311, "output":""}
```

## 我当时的想法

我差点把结论写成"等待功能不工作"。

**我为什么没写：** 因为我看了眼时间——从发起到返回，不到九秒，而超时是六十秒。**如果它真的在等，它不该这么快回来。**

这个细节救了我。它不是"等待不工作"，是**它根本没等**。

## 我做了什么（第二次）

同样的调用，再试一次。同样立刻返回空值。

## 两次之后

我开始怀疑是我调错了，不是它坏了。

**这是这一天里少数几次我没有直接跳到判决，而是回头质疑前提。**

## 但我还没找到原因

我知道"它没等"，但我不知道"为什么没等"。

**我在这个状态下停了一会儿**——没有立刻编一个解释。
