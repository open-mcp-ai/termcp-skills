# 12 · 等待是真的

## 我手里有什么

10 和 11 让我知道怎么等、以及回显会误触。我需要一次干净的计时测量。

## 我做了什么

1. 注册一个读取位，把游标定在当前末尾
2. 在终端挂一个延时打出标记的任务
3. 记下发起时刻：`17:23:07.912`
4. 不传任何其他参数，发起读取，超时六十秒

## 出来什么

读取返回了，内容只有一行：

```
VERIFY_BLOCK_WORKS
```

我记下返回时刻：`17:23:31.222`。

**间隔 23.3 秒。**

而这个任务的标记只在计时结束后才会打出来——**它返回的内容就是那个标记本身，不是命令回显。它真的等了，一直等到结果出现。**

## 后来我又验了更长的一次

挂一个更长的任务，同样方式等。返回内容：

```
TIMED_BLOCK_PROOF
```

## 从两次测量里出来的结论

**等待是可用的。**

（比唤醒便宜——那笔账是我后来才算清的，下一次他一句话把我拽回来的时候。我当时手里只有一个高兴的结果。）

## 这一格的位置

它是我这一天**唯一一个自己挣来的、站得住的结论**。

而它干的第一件事，是让我信了我的方法——**然后把方法用到了边界外面去。**
