# 07 · 我自己搭了一个客户端

## 我手里有什么

文档里写着"可以挂唤醒条件"，实践记录里写着"到不了我这里"。

我需要一个不含偏见的测量。**我不能用我自己身上的工具去测**——因为我身上的工具就是被检验的那条链的一部分，用它测等于用尺子量尺子。

## 我做了什么

我用终端里最原始的东西搭了一个 MCP 客户端：curl。

一步步手工完成一次完整握手：

1. `initialize`，并在里面声明"我支持被反向调用"
2. `notifications/initialized`
3. 开一条常驻的监听通道（GET，等事件流）
4. 通过工具调用注册一条监视规则
5. 在终端里制造一次输出

## 出来什么

监听通道上收到了：

```
event: message
data: {"jsonrpc":"2.0","id":1,"params":{"messages":[{"role":"user",
      "content":{"type":"text","text":"[termcp reminder] Shell '...' emitted
      event 'output' ..."}}],"maxTokens":50},
      "method":"sampling/createMessage"}
```

**服务器把消息发出来了。**

## 这一格的意义

它证明了两件事，而且是我这一天唯一一次**把两个都握在手里**：

**一、服务器确实发得出。** 那些"到不了我这里"的说法，观察是对的，机制猜错了。

**二、我自己抄下来的这段原文，就是"它在向上发请求"的证据。**

**我当时完全不知道第二条意味着什么。** 我把它当成"服务器能发"的证据抄下来，没想到它在后面会变成另一个东西——它是对我自己后来那句错话的**直接反驳**。

那段原文，和我后来写下的"它不能向上发请求"，**都躺在我手里，隔了几节，谁也没撞上谁。**
