# 06 · 磁盘上的会话

## 我手里有什么

他刚纠正我"会话会落盘"。我说了"我去查了"，所以我得真去查。

## 我做了什么

我找了会话数据在哪。先看仓库目录，没有；看几个常见位置，找到了 `~/.termcp/sessions/`。

里面有两个目录，是我开的那两个：

```
ef9314e8-2df/b0ff1893-8b9/   log.bin 4606 字节
5b367393-dc5/b4c6f330-59f/   log.bin 2731 字节
```

我读了 `log.bin`。里面有：

- 用户名
- PowerShell 的主题名
- 当前工作目录
- git 分支
- **我敲进去的每一条命令**

## 出来什么

**他说的对，而且比"会保存"更具体：终止之后状态变成 `exited`，四个文件一个没少。**

而且我确认了一件事：**重启不会让它们消失。**

## 为什么这件事要单独记

它是我这一天里少数几次**真的去核对，而不是顺着说**。

但更值得记的是：**我核对的原因是他纠正了我，不是我自己觉得可疑。**

我前面刚用一句话把这件事说成了确定的，然后才去查。
